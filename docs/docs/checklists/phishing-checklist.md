# Phishing Checklist

Use this checklist before responding to an unexpected message.

## Before clicking

- [ ] I expected to receive this message.
- [ ] I checked the sender’s full email address or phone number.
- [ ] I checked the link destination before clicking.
- [ ] The website address matches the official organisation domain.
- [ ] The message does not pressure me to act immediately.
- [ ] The message does not ask for my password or one-time code.
- [ ] The attachment is expected and from a trusted source.
- [ ] I verified unusual payment or data requests through a known contact.

## If something seems suspicious

- [ ] Do not click links or open attachments.
- [ ] Report the message to IT or the security team.
- [ ] Preserve the original message for investigation.
- [ ] Notify my manager if the message relates to work.
- [ ] Change my password if I may have entered credentials.
- [ ] Report the incident using `docs/incident-reporting-template.md`.
