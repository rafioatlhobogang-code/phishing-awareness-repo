# Phishing Awareness Guide

A small cybersecurity awareness project that helps users recognise phishing
emails, avoid common attacks, and report suspicious messages correctly.

## Purpose

Phishing is a common cyber attack where attackers pretend to be a trusted
person or organisation to trick people into sharing sensitive information,
clicking malicious links, or making unauthorised payments.

## What is included

- `docs/phishing-awareness-guide.md`: Explains phishing and safe responses.
- `docs/incident-reporting-template.md`: A template for reporting suspected phishing.
- `checklists/phishing-checklist.md`: A quick checklist before clicking links or attachments.

## How to use this project

1. Read the phishing awareness guide.
2. Use the checklist when reviewing unexpected emails, SMS messages, or links.
3. Report suspicious messages using the incident-reporting template.

## Key advice

- Do not click links in unexpected messages.
- Verify unusual requests through a known contact method.
- Never share passwords, one-time codes, or sensitive information.
- Report suspected phishing promptly.
